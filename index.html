SETUP HELP

First time opening it? Read this first

Two things catch people out the first time — Windows blocking the app, and a loud squeal when the standalone app opens. Both happened to us setting it up. Here's exactly what to do.

Windows says it won't let the app open

The builds are unsigned (the free way), so Windows Defender may show a blue screen saying it protected your PC, or refuse to open the app. That's Windows not knowing the publisher yet — it is not a virus.

  • Extract the zip first — don't run the app from inside the zip preview. If the zip's Properties show an Unblock box at the bottom, check it, hit Apply, then extract again.
  • On the blue "Windows protected your PC" screen, click More info, then Run anyway.
  • If Defender quarantined the file instead: open Windows Security → Virus & threat protection → Protection history, find VOCAL MASTER 6, and choose Allow or Restore for that file only. Don't turn Defender off — just allow this one app.
  • Still stuck? Skip the standalone and load the VST3 in your DAW — DAWs load unsigned plugins without the warning.

Loud squeal or feedback when the standalone app opens

If the standalone app opens with your mic live and your speakers up, it can squeal — a feedback loop. Before you change anything, turn your audio interface's volume all the way down (muted). A feedback loop gets loud fast, and muted is what keeps it from blasting you while you fix it. Then, in the app:

  • Click Options in the top menu.
  • Click Audio/MIDI Settings.
  • Click the feedback loop setting to break the loop.
  • Keep your interface volume muted while you finish setting up — don't bring it back up yet.
  • Unclick the mute audio input — if the input stays muted, no sound gets into the plugin at all.
  • Make sure your interface is picked as the input and output, then bring the interface volume back up slowly.

This is a standalone-app thing — inside a DAW, the DAW handles the routing, so the loop doesn't come up.
